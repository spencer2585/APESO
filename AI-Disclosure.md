# AI Usage Disclosure
## TLDR:
- This implementation does contain some AI generated code, plans are to eliminate this over the next few versions
- This implementation does not contain any AI generated Assets
- AI has been used as a learning tool to quickly learn how to do new things, caution is taken to make sure everything is done safely and correctly
- As the developer I understand all code in the project and how it works in a detailed manner including the remaining AI generated code

## Extra Details
- The first 2 versions of this mod were heavily AI generated. As of the release of 0.3 much has been rewritten and it is now mostly Human generated
- Despite this there still remains some legacy AI generated code, particularly in the client and early generation
- Over the next few updates I plan to redo the remaining AI generated code at which time all code will be human written
- I do use AI to cover for gaps in knowledge with the intention of learning from it. This is used to find issues early and explain concepts. If any example code is given its purly for learning. All new code for the project is written from scratch
- Additionally, I do have an AI chat with the purpose of keeping track of details like planned features and current dev status. This chat is working under the express instructions to not give me any code.
